# Projeto Individual de SCOM
Este projeto tem o objetivo de criar um site confiável agregador de dados metereológicos do estado de São Paulo


## Estrutura do Projeto
## Requerimentos
Para compilar este projeto é necessário possuir os seguintes programas:
 - `go`
 - `make` \[opcional\]
## Como Executar

### Visualizar o site:
É apenas necessário abrir o arquivo `index.html` diretamente no navegador

### Gerar o site:
```sh
make build
```
### Executar os testes:
```sh
make test
```
